# Lucanet Client Enhancement

为 Lucanet 客户端提供内置增强。安装后继续使用原来的 **Lucanet Software Manager** 或快捷方式，无需额外启动器，也无需编写 Java 代码。

## 功能

- **临时文件提示静默处理**：覆盖 Financial Client 和 Administrator 客户端正常退出、登录过期、会话超时等情况下的“发现未知文件”提示。统一执行“保留文件”，针对所有文件名称和扩展名，不自动删除临时文件。
- **正常退出时归档临时文件**：在客户端原检查之前，递归归档当前客户端临时目录内的全部普通文件，包括隐藏文件、空文件和子目录中的文件。
- **外部链接在新窗口打开**：Financial Client 收到 `ln:goto/LNFC/数据库名称?oid=XXXXX` 链接时，使用原生动作先新建窗口，再跳转到目标。可即时开关。
- **脚本开始按钮与快捷键**：可隐藏脚本运行弹窗的“开始”按钮，并用可编辑快捷键触发原按钮动作，默认 Alt+R。显示方式和快捷键可对已打开的弹窗实时调整。
- **图形化管理**：自动识别或手动选择安装目录，查看安装状态、运行状态和 JDK，一键安装、卸载，并检查和应用更新。

Administrator 指 Lucanet 的管理员客户端程序。增强按实际客户端入口识别，不依赖登录用户名或 Windows 账户名称。登录过期提示、重新登录、账户锁定、保存确认等其他业务提示仍由 Lucanet 原样处理。

## 安装与日常使用

1. 将交付 ZIP **完整解压**到一个目录，双击 `enhancement.exe`。
2. 在工作区确认 Software Manager 安装目录。没有自动识别时，点击“浏览…”选择包含 `LucaNetSoftwareManager.exe` 的文件夹，也可以直接输入路径后点击“检查状态”。
3. 确认 JDK 显示所选安装目录 `.jdk` 中的可用 JDK。
4. 正常关闭 Software Manager、Financial Client 和 Administrator 客户端，等待运行状态显示“未运行”。
5. 点击“安装”。之后继续使用原来的 Software Manager，启动需要的客户端即可。

安装完成后，日常运行不要求增强管理窗口保持打开。通过交付包手动更新增强时，完整解压新的包，关闭上述 Lucanet 程序，再在新包的工作区点击“安装”。仅打开新的管理窗口不会更换已经安装的 Java 增强。

安装目录无写入权限时，可点击“以管理员身份重新打开”。新窗口就绪后旧窗口自动关闭；取消授权或启动失败时保留原窗口。

交付 ZIP 只包含完整功能必需的 6 个运行文件，请一并保留：

```text
enhancement.exe
install.ps1
resolve-lucanet-jdk.ps1
tools/
  gui-core.ps1
  gui-service.ps1
dist/
  client-enhancement.jar
```

不能只拷贝 EXE。README、源码、测试和构建文件无需放进运行目录。ASM 许可已内嵌到 JAR。

## 工作区

| 操作或状态 | 用途 |
| --- | --- |
| 自动识别 | 从常用安装位置、注册表、运行进程和快捷方式识别 Software Manager；有多个安装时可从列表切换。 |
| 浏览… | 手动选择安装目录，支持中文和空格路径。 |
| 检查状态 | 只读刷新安装状态、Lucanet 运行状态和 JDK。 |
| 安装状态 | “已安装”表示启动配置和增强包完整；“当前版本”表示有效模块与本交付包一致；“可更新”表示有差异；“需要修复”时可关闭客户端后重新安装。 |
| Lucanet 运行状态 | 检测所选安装目录的 Manager 和客户端；运行时禁止普通安装和卸载。 |
| JDK | 仅选择所选安装目录 `.jdk` 中完整且版本最高的 JDK，按数字比较版本和构建号；不从 `JAVA_HOME` 或 PATH 选择。 |
| 安装 | 备份原配置，安装交付包内的增强，保留其他 Agent 参数。 |
| 卸载 | 停用原启动链中的增强，保留归档文件和配置备份；再次使用增强时重新安装即可。 |
| 打开Lucanet.Software Manager | 启动所选目录原有的 Software Manager。 |

目录识别和状态检查各有 15 秒等待上限，超时后恢复光标和操作控件，可重试或手动选择目录。自动刷新超时保持静默；安装、卸载和热更新等待事务完成。

Software Manager 升级并生成新的启动配置后，需要重新安装增强，使新的配置接入增强。

## 临时文件处理方式

- **关闭客户端时**：归档当前客户端 `ApplicationPathes.getTempDir()` 指定目录中的普通文件，不扫描 Windows 系统 TEMP。
- **登录过期、超时等非退出阶段**：只静默执行“保留”，文件留在原处，不移动正在使用中的文件。
- **文件被占用或归档失败时**：保留原文件，不阻止其他可移动文件的归档；后续未知文件提示仍静默保留。
- **目录边界**：不跟随符号链接、目录联接，不处理临时目录外的文件。

归档保存在当前用户目录下：

```text
LucaNet-exit-archive/日期时间-pid进程号-随机值/原相对路径
```

每次使用独立目录，保留子目录结构，不覆盖已有归档。可按需要从归档中取回文件。强制结束进程、崩溃或断电不保证执行退出归档。

## 设置 → 功能

### 链接在新窗口中打开

默认开启，仅用于 Financial Client 的外部 OID 链接。原来的调用方式保持不变：

```java
Desktop.getDesktop().browse(
    URI.create("ln:goto/LNFC/lncn_xz?oid=2466470")
);
```

也支持 Lucanet 规范化的 `ln://服务器/goto/LNFC/数据库?oid=数字` 和 `lns://服务器/goto/LNFC/数据库?oid=数字` 形式。完整链接交给原客户端处理，数据库名、其他查询参数和锚点均保留，登录及权限检查仍由 Lucanet 执行。

关闭开关后沿用原窗口导航。切换后**下一次链接立即生效**，无需退出客户端或重新登录，也不依赖自动刷新间隔。新窗口动作执行失败时回到原导航，避免链接被吞掉。

开关保存在当前 Windows 用户的 `%LOCALAPPDATA%/Lucanet/ClientEnhancement/features.properties`，对该用户的已增强客户端生效。

### 脚本运行

进入“设置 → 功能 → 脚本运行”：

- **隐藏“开始”按钮**：默认开启，仅隐藏脚本运行弹窗中的“开始”按钮；关闭后，在原生允许开始的状态恢复显示。不会自动执行脚本，也不改变脚本运行逻辑。已明确保存的开关选择会保留。
- **开始快捷键**：默认 **Alt+R**。点击快捷键输入框后，直接按希望使用的组合键即可保存。支持 Ctrl 或 Alt 配合字母、数字、F1–F12，可同时加入 Shift，例如 Ctrl+Shift+K。不接受单独字母、仅 Shift 组合或 Alt+F4 等系统组合。

快捷键在按钮显示或隐藏时均可使用，只对当前脚本运行弹窗有效，不是全局快捷键。它点击原有“开始”按钮，保留原有的运行前检查、权限、运行锁和运行中状态；不会直接调用脚本引擎。长按组合键不会重复启动。其他处理任务弹窗不受影响。

设置保存后，已打开的脚本弹窗也会更新，无需关闭弹窗、退出客户端或重新登录；更换后使用新的快捷键。配置与跳转设置一起保存在当前 Windows 用户的 `features.properties`，不依赖增强管理窗口或工作区自动刷新保持运行。

### 状态刷新

- **自动刷新**：默认开启，静默检查工作区状态，不显示进度条、不禁用输入、不弹出自动刷新错误。
- **刷新间隔**：默认 8 秒，可设置为 2–300 秒；关闭自动刷新后仍可手动检查。
- **恢复功能默认设置**：恢复开启新窗口链接、隐藏脚本“开始”按钮、Alt+R 快捷键，以及开启自动刷新和 8 秒间隔，保留应用更新设置。

管理界面偏好保存在 `%LOCALAPPDATA%/Lucanet/ClientEnhancement/ui.json`，修改后立即生效。

## 设置 → 应用与更新

应用页提供软件信息、检查更新、自动检查更新、GitHub 仓库和发布页面入口。更新源为 [项目 GitHub Releases](https://github.com/dadazaiddw/Lucanet-Client-Enhancement/releases)。

1. 点击“检查更新”。“自动检查更新”默认关闭，开启后启动管理器时检查一次。
2. 检测到更新且发布提供可校验的完整 ZIP 时，点击“下载更新”。下载不会自动执行安装。
3. 下载包通过大小、SHA-256 和完整运行文件校验后，点击“应用热更新”。
4. 支持热更新的已安装客户端可保持登录，更新运行中的增强模块及下次启动所用模块。不支持热更新、进程身份无法核实或协议不兼容时，按界面提示正常关闭 Lucanet 后安装。

管理界面从已下载的独立目录启动，新窗口就绪后关闭旧窗口。再次打开时请使用新目录中的 `enhancement.exe`；旧快捷方式仍会打开原位置。

更新缓存位于 `%LOCALAPPDATA%/Lucanet/ClientEnhancement/updates`。增强模块另存于 Lucanet 安装目录，日常客户端运行不依赖下载缓存。更新失败时界面保留并显示原因，可重试或从发布页面下载完整包后安装。更新期间请等待操作完成，再启动或退出 Manager、执行其他安装操作。

检查更新只读取稳定发布信息，禁止降级；仓库仅推送源码而未提供完整发布包时，不会成为可下载更新。

## 运行环境与安装位置

管理界面使用 Windows 自带 .NET Framework，后台脚本隐藏运行。Java 增强及维护构建默认使用 Lucanet 安装目录 `.jdk` 中最高版本的完整 JDK；实际客户端 JVM 由 Lucanet 原启动器配置决定。

增强安装在所选 Lucanet 目录的 `.client-enhancement` 中，原生配置备份保存在其 `backups` 子目录。原启动器继续使用，不替换 Lucanet 专有业务 JAR。初次安装和普通卸载均需关闭 Manager 和所有客户端。

项目仓库：[Lucanet Client Enhancement](https://github.com/dadazaiddw/Lucanet-Client-Enhancement)。
