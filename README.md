# Lucanet Client Enhancement

为 Lucanet 客户端提供内置增强。安装后继续使用原来的 **Lucanet Software Manager** 或快捷方式，无需额外启动器，也无需编写 Java 代码。

## 功能

- **临时文件提示静默处理**：覆盖 Financial Client 和 Administrator 客户端正常退出、登录过期、会话超时等情况下的“发现未知文件”提示。统一执行“保留文件”，针对所有文件名称和扩展名，不自动删除临时文件。
- **正常退出时归档临时文件**：在客户端原检查之前，递归归档当前客户端临时目录内的全部普通文件，包括隐藏文件、空文件和子目录中的文件。
- **外部链接在新窗口打开**：Financial Client 收到 `ln:goto/LNFC/数据库名称?oid=XXXXX` 链接时，使用原生动作先新建窗口，再跳转到目标。可即时开关。
- **双击脚本打开运行弹窗**：默认开启，双击脚本栏、自定义财务或报表工作区内的脚本节点，等同点击详情中的“运行”。开关可实时调整，文件夹和其他树节点不受影响。
- **脚本开始按钮与快捷键**：可隐藏脚本运行弹窗的“开始”按钮，并用可编辑快捷键触发原按钮动作，默认 Alt+R。显示方式和快捷键可对已打开的弹窗实时调整。
- **Java 编码辅助**：结合完整源代码及当前脚本的自定义 Class，提供类型与成员补全、参数提示、自动导包与整合、后缀模板及常用 IDEA 编辑操作；支持即时开关与提示字号调整。
- **场景对话框系统边框**：操作设为“显示为对话框”时，使用与脚本运行窗口一致的系统边框及关闭按钮，默认开启；支持对已打开的场景窗口实时切换。
- **图形化管理**：自动识别或手动选择安装目录，查看安装状态、运行状态和 JDK，一键安装、卸载，并检查和应用更新。

Administrator 指 Lucanet 的管理员客户端程序。增强按实际客户端入口识别，不依赖登录用户名或 Windows 账户名称。登录过期提示、重新登录、账户锁定、保存确认等其他业务提示仍由 Lucanet 原样处理。

## 安装与日常使用

1. 将交付 ZIP **完整解压**到一个目录，双击 `enhancement.exe`。
2. 在工作区确认 Software Manager 安装目录。没有自动识别时，点击“浏览…”选择包含 `LucaNetSoftwareManager.exe` 的文件夹，也可以直接输入路径后点击“检查状态”。
3. 确认 JDK 显示所选安装目录 `.jdk` 中的可用 JDK。
4. 正常关闭 Software Manager、Financial Client 和 Administrator 客户端，等待运行状态显示“未运行”。
5. 点击“安装”。之后继续使用原来的 Software Manager，启动需要的客户端即可。

安装完成后，日常运行不要求增强管理窗口保持打开。通过交付包手动更新增强时，完整解压新的包，关闭上述 Lucanet 程序，再在新包的工作区点击“安装”。仅打开新的管理窗口不会更换已经安装的 Java 增强。

安装目录无写入权限时，可点击“以管理员身份重新打开”。新窗口就绪后旧窗口自动关闭；取消授权或启动失败时保留原窗口。

交付 ZIP 只包含完整功能必需的 6 个运行文件，请一并保留：

```text
enhancement.exe
install.ps1
resolve-lucanet-jdk.ps1
tools/
  gui-core.ps1
  gui-service.ps1
dist/
  client-enhancement.jar
```

不能只拷贝 EXE。README、源码、测试和构建文件无需放进运行目录。ASM、IDEA 图标的许可及归属声明已内嵌到 JAR。

## 工作区

打开管理器时直接显示工作区，不显示侧栏。点击右上角齿轮进入设置，设置页左侧可切换“应用”和“功能”，顶部标题跟随所选页签；点击左上角“返回工作区”的图标或文字即可返回。

| 操作或状态 | 用途 |
| --- | --- |
| 自动识别 | 从常用安装位置、注册表、运行进程和快捷方式识别 Software Manager；有多个安装时可从列表切换。 |
| 浏览… | 手动选择安装目录，支持中文和空格路径。 |
| 检查状态 | 只读刷新安装状态、Lucanet 运行状态和 JDK。 |

| Lucanet 运行状态 | 检测所选安装目录的 Manager 和客户端；运行时禁止普通安装和卸载。 |
| JDK | 仅选择所选安装目录 `.jdk` 中完整且版本最高的 JDK，按数字比较版本和构建号；不从 `JAVA_HOME` 或 PATH 选择。 |

目录识别和状态检查各有 15 秒等待上限，超时后恢复光标和操作控件，可重试或手动选择目录。自动刷新超时保持静默；安装、卸载和热更新等待事务完成。

Software Manager 升级并生成新的启动配置后，需要重新安装增强，使新的配置接入增强。

## 临时文件处理方式

- **关闭客户端时**：归档当前客户端 `ApplicationPathes.getTempDir()` 指定目录中的普通文件，不扫描 Windows 系统 TEMP。
- **登录过期、超时等非退出阶段**：只静默执行“保留”，文件留在原处，不移动正在使用中的文件。
- **文件被占用或归档失败时**：保留原文件，不阻止其他可移动文件的归档；后续未知文件提示仍静默保留。
- **目录边界**：不跟随符号链接、目录联接，不处理临时目录外的文件。

归档保存在当前用户目录下：

```text
LucaNet-exit-archive/日期时间-pid进程号-随机值/原相对路径
```

每次使用独立目录，保留子目录结构，不覆盖已有归档。可按需要从归档中取回文件。强制结束进程、崩溃或断电不保证执行退出归档。

## 设置 → 功能

### 链接跳转

默认开启，仅用于 Financial Client 的外部 OID 链接。原来的调用方式保持不变：

```java
Desktop.getDesktop().browse(
    URI.create("ln:goto/LNFC/lncn_xz?oid=2466470")
);
```

也支持 Lucanet 规范化的 `ln://服务器/goto/LNFC/数据库?oid=数字` 和 `lns://服务器/goto/LNFC/数据库?oid=数字` 形式。完整链接交给原客户端处理，数据库名、其他查询参数和锚点均保留，登录及权限检查仍由 Lucanet 执行。

关闭开关后沿用原窗口导航。切换后**下一次链接立即生效**，无需退出客户端或重新登录，也不依赖自动刷新间隔。新窗口动作执行失败时回到原导航，避免链接被吞掉。

开关保存在当前 Windows 用户的 `%LOCALAPPDATA%/Lucanet/ClientEnhancement/features.properties`，对该用户的已增强客户端生效。

### 脚本运行

进入“设置 → 功能 → 脚本运行”：

- **双击脚本打开运行弹窗**：默认开启，支持“脚本”栏和自定义财务、报表工作区中的脚本，包括普通脚本、工作区中的脚本层级元素、多维包装节点及程序型脚本详情。双击脚本节点后，调用该脚本原有“运行”按钮来打开弹窗，不自动点击“开始”或执行脚本。关闭后恢复原双击行为，原“运行”按钮仍可使用。修改后下一次双击立即生效，无需重新登录或重开客户端。切换到其他详情页签也可以双击打开；原按钮不可用或所选节点与详情/配置模型不一致时，不打开其他脚本。文件夹、非脚本元素和数值列仍使用原来的展开或钻取操作。

- **隐藏“开始”按钮**：默认开启，仅隐藏脚本运行弹窗中的“开始”按钮；关闭后，在原生允许开始的状态恢复显示。不会自动执行脚本，也不改变脚本运行逻辑。已明确保存的开关选择会保留。
- **“开始”快捷键**：默认 **Alt+R**。点击快捷键输入框后，直接按希望使用的组合键即可保存。支持 Ctrl 或 Alt 配合字母、数字、F1–F12，可同时加入 Shift，例如 Ctrl+Shift+K。不接受单独字母、仅 Shift 组合或 Alt+F4 等系统组合。

快捷键在按钮显示或隐藏时均可使用，只对当前脚本运行弹窗有效，不是全局快捷键。它点击原有“开始”按钮，保留原有的运行前检查、权限、运行锁和运行中状态；不会直接调用脚本引擎。长按组合键不会重复启动。其他处理任务弹窗不受影响。

设置保存后，已打开的脚本弹窗也会更新，无需关闭弹窗、退出客户端或重新登录；更换后使用新的快捷键。配置与跳转设置一起保存在当前 Windows 用户的 `features.properties`，不依赖增强管理窗口或工作区自动刷新保持运行。

### Java 编码辅助

进入“设置 → 功能 → Java 编码辅助”，默认开启。开关约 250 毫秒内作用于已打开的 Java 脚本编辑框，不依赖管理器保持打开；保留未保存文本、选区及原文档。关闭后恢复原键位与编辑选项。SQL、普通文本和只读编辑框不应用此功能。

输入标识符或点号后自动弹出候选，也可按 **Ctrl+Space**。分析将当前未保存文本放回“源代码”对应的方法或成员中，保留包名、导包、方法参数和其他类成员，并一起分析同一脚本 Class 树内的自定义类。无需先打开每个 Class 的源代码页；新增、修改、删除 Class 在下次请求时重新读取，切换脚本后不沿用前一脚本的类。

支持局部变量、自定义类的静态方法与常量、JDK 及当前客户端依赖库中的公共类、泛型成员和链式调用。按名称匹配、可推断的赋值/返回类型及作用域排序，优先展示局部变量、已导入类和当前脚本的 Class。类候选显示 `List<E>`、`Map<K, V>` 等泛型声明，自定义 Class 的泛型同样可见；灰色泛型声明用于展示，选择类时插入类名。包名紧跟类名左对齐，方法返回类型靠右对齐。长参数列表按实际可用宽度尽量显示文字，只缩略放不下的末尾并保留右括号，不会一次隐藏整个长泛型参数。选中被省略的候选后，该行自动展开完整签名，其他候选保持原布局；屏幕宽度不足时完整参数换行，返回类型继续保留。完整包名或返回类型优先显示；极长包名/类型在有限屏幕宽度下换行，不使用横向滚动条。鼠标悬停也可查看完整签名。↑/↓ 选择，Enter、Tab 或双击插入，Esc 关闭。分类图标使用 [JetBrains 官方 New UI 图标](https://github.com/JetBrains/intellij-community/tree/d7df0859f40738ac02e00808f894fce9828ba781/platform/icons/src/expui/nodes)，区分类、接口、异常、方法、字段、局部变量、参数与模板，并叠加静态/final 标记。中文来源说明及中文标识符使用支持中文的字体回退。

输入 `(` 或 `,` 后自动提示参数，也可在调用括号内按 **Ctrl+P**。开始输入参数表达式时优先切回对应的变量、类和成员补全，例如 `forEach(System.)` 显示 `System` 成员；Ctrl+P 仍可手动查看当前调用的参数。即使 `new File()` 尚未填入必需参数，也列出可访问的构造器重载；按已输入实参类型排序，并高亮当前参数，长签名缩略时优先保留当前参数。支持嵌套调用、字符串中的逗号和数组初始化，光标在参数字符串内也能手动查看。注释、字符串、字符及文本块内不触发普通 Java 补全。

上下键连续切换时，完整签名直接跟随选中项更新，无需停留等待展开；长签名之间切换保持展开层可见。输入新文本、切换源码上下文或修改字号后重新计算显示内容。

“代码提示字号”默认 **18**，范围 **12–30**；修改后约 250 毫秒内更新补全列表与参数提示，已展开的提示框也会更新。恢复默认设置会同时恢复字号 18。

从候选中选择类时，自动加入 Lucanet **类结构中的导包节点**，使用原生变更通知及保存流程；不向方法体插入 `import`。也可把光标放在类名上按 **Alt+Enter**，从同名类中选择需要的包。已有导包不重复添加，同包自定义 Class 无需导入；同名类冲突或不具备原生导包上下文时，使用完整类名。

自动导包后或按 **Ctrl+Alt+O** 时整合并排序导包：同包达到 **2 个可编辑的类导入**时合并为 `package.*`，例如 `java.io.File` 与 `java.io.IOException` 合并为 `java.io.*`。已打开脚本编辑器也会检测原生 import 树的变化，短暂等待后自动整理手动添加的导包。已有通配导包时清理其覆盖的重复导入。保留 `Date`、`List` 等同名歧义需要的显式导入，以及 Lucanet 隐藏/不可删除和静态导入；不删除仅因当前方法未使用的其他导包。关闭 Java 编码辅助时停止自动整理。

快捷键采用 [IntelliJ IDEA Windows 默认键位](https://www.jetbrains.com/help/idea/reference-keymap-win-default.html)：

| 功能 | 快捷键 |
| --- | --- |
| 基本代码补全 | Ctrl+Space |
| 方法/构造器参数提示 | Ctrl+P |
| 当前类名导包候选 | Alt+Enter |
| 整合并排序导包 | Ctrl+Alt+O |
| 复制当前行或选区 | Ctrl+D |
| 删除当前行或所选行 | Ctrl+Y |
| 切换行注释 | Ctrl+/ |
| 块注释/取消所选块注释 | Ctrl+Shift+/ |
| 上移/下移当前行或所选行 | Alt+Shift+↑ / ↓ |
| 在当前行之后开始新行 | Shift+Enter |
| 合并下一行 | Ctrl+Shift+J |
| 调整选区/当前代码缩进 | Ctrl+Alt+I |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Shift+Z |
| 展开代码模板 | 模板名后按 Tab |

模板包含 `sout`、`serr`、`fori`、`iter`、`ifn`、`inn`。保留原语法高亮，增强括号匹配、高亮同名标识符与大括号补齐。编辑动作接入原撤销历史；导包属于原生类结构变更，撤销文本时保留导包，可在类结构中管理。输入法占用 Ctrl+Space 时，请在输入法设置中释放此键位。

支持 [IDEA 风格后缀补全](https://www.jetbrains.com/help/idea/postfix-code-completion.html)，输入后缀后按 Tab，或从候选中选择：

| 输入 | 展开效果 |
| --- | --- |
| `File.new` | `new File()`，光标进入参数，提示构造器；未导包时提供类导入候选。 |
| `value.sout` | `System.out.println(value);` |
| `value.return` | `return value;` |
| `value.nn` / `value.null` | 非空/为空判断代码块。 |
| `ready.if` | 布尔条件判断代码块。 |
| `ready.not` | `!(ready)` |

后缀模板依据表达式类型显示，语句模板只在语句位置提供；展开保留所在行缩进，并能用一次原生撤销恢复。`.new` 仅在当前代码位置可以访问至少一个构造器时提供：只有私有构造器的工具类不向外部调用方展示 `new`，类内部的合法调用仍保留；参数提示使用相同的构造器访问规则。

分析使用当前客户端 JDK 的 Java 编译器及实际加载的依赖位置，在后台进行；不执行脚本、不生成 class、不运行注解处理器。首次类索引可能需要短暂等待。此功能提供常用编码辅助，不包含 IDEA 的项目级重构、调试器、完整格式化及全部检查器；复杂或尚未完整输入的表达式、其他脚本的动态生成类型可能无法推断。无法解析或缺少完整 JDK 时保留原编辑与保存。参数名取决于库是否保留元数据，缺少时显示 `arg0` 等名称。

### 场景对话框

“使用系统边框和关闭按钮”默认开启，仅调整操作设为“显示为对话框”的场景弹窗。开启后采用与“运行脚本”窗口一致的系统标题栏、边框和关闭按钮；关闭后恢复原紫色边框和关闭按钮。

场景弹窗的标题文字始终为空，切换边框样式或场景更新标题时也不显示文字；系统边框开启时仍保留标题栏和关闭按钮。该处理不改变场景原有的标题数据。

修改后约 250 毫秒内更新已打开的场景窗口，无需重开弹窗或重新登录；保留当前输入、选区、窗口位置及模态状态，系统关闭按钮仍执行该场景原有的关闭动作。有子对话框或原生下拉弹窗显示时，待其关闭后应用样式。该设置不改变场景执行逻辑，也不影响其他类型弹窗。

## 设置 → 应用

应用页提供软件信息、检查更新、自动检查更新、状态刷新设置、GitHub 仓库和发布页面入口。更新源为 [项目 GitHub Releases](https://github.com/dadazaiddw/Lucanet-Client-Enhancement/releases)。

### 状态刷新

- **自动刷新**：默认开启，静默检查工作区状态，不显示进度条、不禁用输入、不弹出自动刷新错误。
- **刷新间隔**：默认 8 秒，可设置为 2–300 秒；关闭自动刷新后仍可手动检查。

管理界面偏好保存在 `%LOCALAPPDATA%/Lucanet/ClientEnhancement/ui.json`，修改后立即生效。

### 更新

1. 点击“检查更新”。“自动检查更新”默认关闭，开启后启动管理器时检查一次。
2. 检测到更新且发布提供可校验的完整 ZIP 时，点击“下载更新”。下载不会自动执行安装。
3. 下载包通过大小、SHA-256 和完整运行文件校验后，点击“应用热更新”。
4. 支持热更新的已安装客户端可保持登录，更新运行中的增强模块及下次启动所用模块。不支持热更新、进程身份无法核实或协议不兼容时，按界面提示正常关闭 Lucanet 后安装。

管理界面从已下载的独立目录启动，新窗口就绪后关闭旧窗口。再次打开时请使用新目录中的 `enhancement.exe`；旧快捷方式仍会打开原位置。

更新缓存位于 `%LOCALAPPDATA%/Lucanet/ClientEnhancement/updates`。增强模块另存于 Lucanet 安装目录，日常客户端运行不依赖下载缓存。更新失败时界面保留并显示原因，可重试或从发布页面下载完整包后安装。更新期间请等待操作完成，再启动或退出 Manager、执行其他安装操作。

检查更新只读取稳定发布信息，禁止降级；仓库仅推送源码而未提供完整发布包时，不会成为可下载更新。

## 恢复默认设置

设置页侧栏底部的“恢复默认设置”开启新窗口链接、双击脚本运行弹窗、Java 编码辅助、场景对话框系统边框，隐藏脚本“开始”按钮，恢复 Alt+R 快捷键，以及开启自动刷新和 8 秒间隔。应用更新设置仍保留。

## 运行环境与安装位置

管理界面使用 Windows 自带 .NET Framework，后台脚本隐藏运行。Java 增强及维护构建默认使用 Lucanet 安装目录 `.jdk` 中最高版本的完整 JDK；实际客户端 JVM 由 Lucanet 原启动器配置决定。

增强安装在所选 Lucanet 目录的 `.client-enhancement` 中，原生配置备份保存在其 `backups` 子目录。原启动器继续使用，不替换 Lucanet 专有业务 JAR。初次安装和普通卸载均需关闭 Manager 和所有客户端。
