# Lucanet Client Enhancement

面向 Lucanet 桌面客户端的功能增强工具，改善脚本开发、窗口操作和临时文件处理体验。

**安装一次，继续通过原来的 Lucanet Software Manager 启动客户端。** 日常使用无需额外启动器，也无需保持增强管理窗口运行。

## 快速开始

### 运行条件

- Windows 桌面环境，已安装 Lucanet Software Manager 及需要使用的客户端。
- 系统具备 Windows PowerShell 和 .NET Framework，供增强管理器及安装脚本使用。
- Lucanet 安装目录的 `.jdk` 下存在完整 JDK。管理器默认选择其中版本最高、工具完整的 JDK，不使用 `PATH` 或 `JAVA_HOME` 中的 Java。
- 安装时需要对所选 Lucanet 目录有写入权限。

增强安装到客户端启动链，继续使用 Lucanet 原有的登录、权限、编译和执行流程。可同步到原生 Class 的普通 Java 类支持由 Lucanet 脚本引擎重新编译，包括服务器任务。

### 安装

1. 在 [Releases](https://github.com/dadazaiddw/Lucanet-Client-Enhancement/releases) 下载项目发布的完整运行 ZIP。GitHub 自动生成的 `Source code` 压缩包是源码包。
2. **完整解压**，进入 `lucanet-client-enhancement` 文件夹，双击 `enhancement.exe`。
3. 在工作区确认 Software Manager 安装目录。未自动识别时，点击“浏览…”选择包含 `LucaNetSoftwareManager.exe` 的文件夹，再检查状态和 JDK。
4. 正常关闭 Software Manager、Financial Client 和 Administrator，等待运行状态显示“未运行”。
5. 点击“安装”。完成后，通过原来的 Software Manager 或快捷方式启动客户端。

遇到目录权限不足，可点击“以管理员身份重新打开”。新窗口就绪后旧窗口关闭；取消授权或启动失败时，原窗口保留。

### 运行包目录

解压后只有一个顶层文件夹，其中包含完整功能需要的 **6 个文件**：

```text
lucanet-client-enhancement/
├── enhancement.exe
├── install.ps1
├── resolve-lucanet-jdk.ps1
├── tools/
│   ├── gui-core.ps1
│   └── gui-service.ps1
└── dist/
    └── client-enhancement.jar
```

请保留目录结构，不能只复制 EXE。README、源码和许可证保留在源码仓库中；审计材料和测试文件仅在本地维护，不提交到 GitHub，也不放入运行包。运行包中的 JAR 内嵌第三方许可与归属说明。

### 从源码构建

源码仓库包含 Java 和管理器源码、运行资源、许可证，以及构建和安装脚本。EXE、JAR 和运行 ZIP 由本地构建生成，不提交到 GitHub。

在 Windows PowerShell 中进入项目目录，执行：

```powershell
.\build.ps1 -LucanetHome 'D:\Soft\LucaNet'
.\package.ps1
```

将 `-LucanetHome` 改为实际的 Software Manager 安装目录。构建自动选择该目录 `.jdk` 中版本最高的完整 JDK，使用 `.resource` 中的 `asm-9.7.jar`、`asm-commons-9.7.jar`，并通过系统 .NET Framework 编译管理器。

构建结果为项目根目录的 `enhancement.exe` 和 `dist/client-enhancement.jar`。打包后可使用 `dist/lucanet-client-enhancement.zip`，完整解压后按上面的安装步骤使用。

## Java 脚本开发

### 创建与编辑自定义类型

1. 在增强插件的 **设置 → 代码** 中开启 **自定义 Java 类型**。进入脚本编辑模式，选中 **Class 文件夹或其子文件夹**，按 **Alt+Insert**。
2. 输入类型名称，选择 `Class`、`Interface`、`Record`、`Enum`、`Annotation`、`Exception` 或 `Abstract Class`，按 Enter 创建。名称不包含包名或 `.java` 后缀。

3. 在独立窗口编辑完整源码。初始包名及导包来自当前 Lucanet 的 Class 模板，可以继续编辑继承、接口实现、泛型、字段和方法。
4. 按 **Ctrl+S**，或正常关闭源码窗口，将源码保存到原生 Class 节点。新节点会立即出现在左侧树中。
5. **再按 Lucanet 原来的方式保存脚本。** 单击节点查看详情，双击重新打开完整源码编辑窗口。

`Exception` 模板默认继承 `RuntimeException`，并生成接收 `String message`、调用 `super(message)` 的构造方法。继承类仍按原生客户端和服务器的限制显示兼容提示。

源码窗口默认占所在显示器可用宽度的 **75%**、高度的 **70%**，约为半屏面积，避开任务栏并居中；支持拖动、调整大小和最大化。字号设置即时应用到源码窗口、类型选择窗口、补全列表、参数提示及方法生成窗口。

完整源码随原生 Class 节点和脚本保存、导出、重新加载，不需要额外的 `.java` 文件。完整源码类型的结构详情显示只读摘要，修改类型名称和内容请使用源码窗口。其他普通 Class 保留原生结构编辑方式。

#### 在原生客户端和服务器运行

普通类请保留 Class 模板包名 `com.lucanet.common.dom.script.rt` 和 `public class Test` 声明。保存时会把可表示的导入、字段、构造方法和方法同步到原生 Class。原生客户端和服务器可从这些部件重编译，包括带参数的构造方法。

增强源码窗口隐藏 Lucanet 生成的 `Variables`、`Methods`、`End of Class` 等分隔注释和 `CallStack` 的 `try/finally` 包装，保留手写的注释和 `try/finally`。普通类同步后，增强客户端和原生客户端的「源代码」页都由 Lucanet 生成这些注释和包装。同步时清除方法体首尾空行和外层缩进，统一同一行赋值和二元运算符两侧的空格。增强窗口按类中的位置补回缩进，两端都保留内部空行、相对缩进和字符串内容。旧版保存的普通类可按 **Ctrl+S** 重新同步方法体格式，再保存脚本。

迁移旧脚本时，双击打开脚本调用的每个普通自定义 Class，按 **Ctrl+S**。看到“已同步到原生 Class”后，再用 Lucanet 保存整个脚本并重跑服务器任务。原样保存也能补写旧类的原生部件。

原生 Class 无法还原 `extends`、`implements`、Record 等增强类型的完整定义。比如增强端编译 `public class Test implements Comparator` 时会使用完整源码。原生端重新生成的 `Test` 缺少 `Test(String, int)`，`Main` 中的 `new Test("1", 2)` 因此会编译失败。

源码窗口底部和类结构详情会以红字提示原生客户端及服务器无法还原的原因，长提示随窗口宽度换行。已同步的普通类在原生客户端保存脚本后，增强客户端重新载入脚本会按最新的原生导入、字段、构造方法和方法显示源码并编译。遇到未保存的草稿或只有增强客户端能还原的类，编辑器会提示手动合并，并保留现有源码。

回读原生修改时，增强窗口会恢复原完整源码中的类、字段和方法声明注释；方法体采用原生端最新内容。已删除或无法匹配的成员注释保留在类尾部，原生草稿有语法错误时无法定位的注释保留在文件开头并显示红色提示。回读后按 **Ctrl+S** 可将源码与原生修改重新建立同步基线。

原生 Class 的内置导入不能删除。例如，只保留 `java.util.*` 并使用 `Date`，原生生成器可能将其绑定为 `ln.source.api.Date`。此类情况会显示红字并保留增强源码，避免静默改变含义；使用 `java.util.Date` 等完整类型名后可恢复同步。类级别的泛型、继承、接口实现等仍需额外应用程序库；普通类的方法泛型和 `var` 局部变量可写入原生方法体。

- **只在脚本中构造并读取对象。** 移除 `implements Comparator`，同时移除 `compare` 方法上的 `@Override`。保留构造方法、访问器和 `equals`、`hashCode`、`toString` 的 `@Override`。按 Ctrl+S 同步到原生 Class 后，再保存脚本。
- **保留接口关系。** 将类型移到自有包，编译成带 `module-info.java` 的 JAR，并通过模块声明 `exports` 该包。在同一 Lucanet 环境的 Administrator 中启用并上传到「额外应用程序库」。从脚本的 Class 树移除已迁入库的同名类，在 `Main` 及其他引用处导入库中的类型。库加载后，重新打开脚本并编译，再运行服务器任务。

遇到语法错误、重名、节点已在其他位置修改，或原脚本已经关闭、切换、不可编辑时，保存会显示原因并保留窗口中的草稿。确认不需要修改时，可点击“放弃修改”。关闭“自定义 Java 类型”只关闭创建和双击入口，已打开的草稿仍可保存，已保存类型仍参与客户端编译。

> Record 等语法受实际客户端 JVM 限制。管理器选择的维护 JDK，不会替换 Lucanet 原启动器为客户端选择的 JVM。

### 补全与参数提示

在可编辑的 Java 代码中输入标识符、`.` 或 `@` 自动触发补全，也可按 **Ctrl+Space**。使用 ↑/↓ 选择，Enter、Tab 或双击插入，Esc 关闭。

补全结合当前未保存代码、方法参数、类成员、同一脚本 Class 树内的自定义类型，以及 Lucanet 已加载的 Administrator 额外应用程序库，支持局部变量、静态成员、泛型和链式调用。候选显示类型图标、泛型声明、来源包名及返回类型；选中被省略的长签名时展开完整内容，屏幕宽度不足时换行显示。

选择方法候选或 `new` 后的类型候选时自动补齐 `()`，包括无参方法，光标进入括号内。已有括号、参数和构造器泛型参数会保留；声明类型时只插入类型名。`对象::方法`、`类型::方法` 的方法引用补全保留引用语法。

输入 `(` 或 `,` 自动提示方法或构造器参数；在调用括号内按 **Ctrl+P** 可手动查看。参数提示区分可访问的重载，并高亮当前参数。开始输入参数表达式时，优先显示变量、类和成员补全；需要继续查看签名时再次按 Ctrl+P。

输入 `@` 后，候选限定为当前可用的注解类型，包含 JDK、当前脚本和已加载额外库中的注解。例如 `@Over` 匹配 `Override`，`@Doc` 匹配 `Documented`；也支持 `@java.lang.Dep` 这样的包名输入。选择候选时按需导包，已有包名前缀不会重复插入；注解参数内继续使用普通表达式补全。

分析在后台使用当前客户端 JDK 的编译器及已加载依赖，不执行脚本或注解处理器。首次建立索引可能需要稍候。SQL、普通文本、只读编辑框，以及 Java 注释、字符串内的普通输入，不触发常规代码补全。

Lombok 等依赖的编译与注解处理遵循 Lucanet 原生方式，增强插件不修改原生编译器选项，也不运行其处理器。编辑器不会推断尚未编译的注解生成成员；此类成员的最终可用性以 Lucanet 原生编译结果为准。需要在源码中明确生成方法时，可使用 Alt+Insert。

### 自动导包与整理

选择类候选时自动处理导包，也可以把光标放在类型名称上按 **Alt+Enter**，从同名类中选择需要的类型。

- **原生方法片段编辑器**：导包写入 Lucanet 类结构中的 import 节点，不写入方法体。文本撤销与类结构导包分开管理。
- **完整源码窗口**：导包直接写入源码。补全和方法生成优先采用简短类名；`java.lang` 类型无需 import。生成的方法及其新增导包可以一起撤销。
- **同名冲突**：已有显式导包、同包类型、内部类或泛型参数与目标类型重名时，保留必要的全限定名，避免改变已有代码的类型含义。

按 **Ctrl+Alt+O** 整合并排序导包。同包达到两个可编辑类导入时可合并为 `package.*`；保留 `Date`、`List` 等名称消歧需要的显式导入、静态导入和 Lucanet 隐藏或不可删除的导入。不会仅因为当前方法未使用某个类，就删除其他方法可能需要的导包。

自动导包和原生导包树变化也会触发整理。为保持一次撤销的完整性，方法生成不会再由后台追加一次独立的导包整理操作；需要合并时可手动按 Ctrl+Alt+O。

### 快速修复与重写方法

完整源码窗口在暂停输入后标记编译错误。点击底部错误提示可跳转到对应位置；按 **Alt+Enter** 查看当前位置可用的导包、补分号或实现缺少抽象方法等修复。

在类中按 **Ctrl+O**，多选需要重写或实现的方法并生成。生成结果使用短类名和所需导包；抽象方法的默认方法体是待实现骨架，需要补充业务逻辑。

### Alt+Insert 生成方法

在完整源码窗口中，将光标放到希望插入方法的位置，按 **Alt+Insert** 打开 **Generate** 菜单。菜单使用 IDEA 风格的标题、圆角和选中状态；直接输入即可搜索，按命令名称进行不区分大小写的包含匹配。例如输入 `s`，可筛选出 Constructor、Setter、equals/hashCode、toString 等名称包含 `s` 的命令。

按 ↑/↓ 选择、Enter 确认、Backspace 删除搜索字符；Ctrl+Backspace 清空搜索。搜索时按 Esc 清空，再按 Esc 关闭菜单；没有搜索词时 Esc 直接关闭。菜单内按 Ctrl+O 也可进入重写方法选择。

| 菜单项 | 行为与规则 |
| --- | --- |
| Constructor | 选择当前类字段及可访问的父类构造器；未初始化的 final 字段必选，已初始化的 final 字段不进入参数。 |
| Getter | 根据字段类型生成访问方法；boolean 使用 `isXxx`，Boolean 使用 `getXxx`。 |
| Setter | 生成字段赋值方法；final 字段不生成 Setter。 |
| Getter and Setter | 一次生成所选字段的访问及赋值方法。 |
| equals() and hashCode() | 使用 `java.util.Objects` 模板分步选择比较方式和字段，成对生成。数组按内容比较并计算对应哈希。 |
| toString() | 使用字符串拼接模板，String 字段带单引号，数组展示内容；可选择调用 Getter、添加 @Override 及包含父类结果。 |
| Override Methods... | 进入重写 / 实现方法选择窗口，与 Ctrl+O 对应。 |

字段窗口按类别显示标题及可用模板，以列表选中状态表示参与生成的字段。支持 Ctrl / Shift 多选、空格切换、Select All / Select None；Search 可按字段名或类型筛选，筛选时保留已选字段。Enter 执行当前默认按钮，Esc 取消。构造方法有多个可用父类构造器时，先选择父类构造器，再选择当前类字段；未初始化的 final 字段始终保留选中。

equals/hashCode 的选择流程如下：

1. 使用 `java.util.Objects` 模板，选择 `getClass()` 或 `instanceof` 类型检查，可选择调用现有 Getter 及父类方法。
2. 选择参与 equals 的字段。
3. 选择参与 hashCode 的字段，候选限定在上一步字段内，避免破坏相等对象哈希一致的约定。
4. 有引用类型字段时，可标记保证非空的字段；默认不选。只为业务上始终非空的字段启用此项。点击 Finish 生成，Back 可返回修改。

默认模板与 IDEA 常用生成结果一致。例如类 `Test` 中有 `String s` 和 `int i` 时，equals 先比较 `i`，再用 `Objects.equals(s, test.s)` 比较字符串；hashCode 为：

```java
@Override
public int hashCode() {
    return Objects.hash(s, i);
}
```

单字段和数组会采用对应的 `Objects.hashCode`、`Arrays.hashCode` 或 `Arrays.deepHashCode`，保证数组内容与 equals 的语义一致。需要的工具类自动导包。

**生成结果插入打开菜单时的源码光标位置。** 光标在方法体、字段初始化表达式或初始化块中时，插入到该成员之后的合法位置；保留注释和原有成员顺序。不会统一追加到类末尾。生成代码及新增导包支持一次 Ctrl+Z 撤销，取消弹窗不修改源码。

菜单及字段窗口跟随字号设置。生成使用当前类实例字段，排除静态字段；已有方法及不可重写的父类方法会跳过。已有 equals 或 hashCode 时不会只生成另一半，应先检查现有实现的一致性。

字段方法生成适用于普通类、抽象类和异常类。接口、枚举、注解及 Record 不提供这组字段生成器；适用时可使用 Ctrl+O。匿名类中的生成请求不会转移到外部类。

**同一个快捷键对应两个位置：Class 树中的 Alt+Insert 新建类型，源码窗口中的 Alt+Insert 生成方法。**

### 快捷键速查

以下编码辅助快捷键需要开启“Java 编码辅助”。自定义类型创建及保存由独立的类型编辑功能提供。

| 快捷键 | 功能 | 使用位置 |
| --- | --- | --- |
| Alt+Insert | 新建 Java 类型 | Class 文件夹或子文件夹 |
| Ctrl+S | 保存到原生 Class 节点 | 完整源码窗口 |
| Ctrl+Space | 代码补全 | Java 编辑器 |
| Ctrl+P | 方法 / 构造器参数提示 | Java 编辑器 |
| Alt+Enter | 导包或当前位置可用的快速修复 | Java 编辑器；诊断修复在完整源码窗口 |
| Ctrl+O | 重写 / 实现方法 | 完整源码窗口 |
| Alt+Insert | 生成构造方法、Getter / Setter、equals/hashCode、toString | 完整源码窗口 |
| Ctrl+Alt+O | 整合并排序导包 | Java 编辑器 |
| Ctrl+D | 复制当前行或选区 | Java 编辑器 |
| Ctrl+Y | 删除当前行或所选行 | Java 编辑器 |
| Ctrl+/ | 切换行注释 | Java 编辑器 |
| Ctrl+Shift+/ | 添加 / 取消所选块注释 | Java 编辑器 |
| Alt+Shift+↑ / ↓ | 上移 / 下移当前行或所选行 | Java 编辑器 |
| Shift+Enter | 在当前行之后开始新行 | Java 编辑器 |
| Ctrl+Shift+J | 合并下一行 | Java 编辑器 |
| Ctrl+Alt+I | 调整当前代码或选区缩进 | Java 编辑器 |
| Ctrl+Z / Ctrl+Shift+Z | 撤销 / 重做 | Java 编辑器 |
| Tab | 展开模板或后缀补全 | Java 编辑器 |

常用模板包括 `sout`、`serr`、`fori`、`iter`、`ifn`、`inn`。输入后缀后按 Tab，或从补全候选中选择：

| 输入示例 | 展开效果 |
| --- | --- |
| `File.new` | `new File()`，光标进入参数位置并提示构造器；未导包时提供类型候选。 |
| `value.sout` | `System.out.println(value);` |
| `expression.var` | 推断具体类型和变量名，例如 `getCustomer().var` → `Customer customer = getCustomer();`，自动避开重名并选中变量名。 |
| `value.return` | `return value;` |
| `value.nn` / `value.null` | 非空 / 为空判断代码块。 |
| `ready.if` | 布尔条件判断代码块。 |
| `ready.not` | `!(ready)` |

模板根据表达式类型及当前位置提供；`.new` 只展示当前作用域可访问的构造器。展开保留缩进，可以一次撤销。编辑器保留原生语法高亮，并增强括号匹配、同名标识符高亮。

`.var` 用于方法或代码块中的独立表达式，按 **Tab** 展开，也可选择补全候选。不适用于 `void` 调用、单独的 `null` 或只能放单条语句的位置；已有分号会合并，展开与变量名选中一起支持一次撤销。

类型推断保留基本类型、数组和泛型，例如 `List.of("x").var` 会生成 `List<String> strings = List.of("x");`；变量名结合 getter、调用名称、数组或集合元素类型推断，遇到重名依次添加数字。匿名类和无法直接引用的内部类型使用可访问的父类、接口或通配符。完整源码窗口自动添加所需导入，类型重名时保留全限定名；原生方法编辑区使用已有导入或全限定名。无法可靠解析的表达式不生成声明。

输入 `"`、`'`、`(`、`[`、`{` 时，在代码位置自动补上另一半并将光标放在中间。选中文本后输入左符号可包裹选区；再次输入已有右符号会越过它，空符号对内按 Backspace 一起删除。空花括号内按 Enter 会展开为缩进代码块。选区包裹、成对删除和展开换行均支持一次撤销；注释、字符串内容、文本块及粘贴内容按原文输入。

编码辅助覆盖常用编辑场景，不包含完整 IDE 的项目级重构、调试器和全部检查规则。尚未输入完整的表达式、未加载的库或其他脚本的动态类型可能无法推断；无法解析或缺少完整 JDK 时保留原编辑与保存能力。库没有保留参数名时，提示可能显示 `arg0` 等名称。

## 客户端操作增强

### 外部链接在新窗口打开

“设置 → 界面”中的链接开关用于 Financial Client 的外部 OID 跳转，默认开启。支持以下链接格式：

```text
ln:goto/LNFC/数据库名称?oid=123456
ln://服务器/goto/LNFC/数据库名称?oid=123456
lns://服务器/goto/LNFC/数据库名称?oid=123456
```

开启后，客户端先执行原生“新窗口”动作，再处理完整链接；数据库名、其他查询参数和锚点保留，登录及权限检查仍由 Lucanet 执行。关闭后恢复原窗口导航；新窗口动作失败时回到原导航。设置在下一次链接跳转时生效。

### 脚本运行弹窗与快捷键

双击脚本节点可打开原生运行弹窗，覆盖“脚本”栏、自定义财务或报表工作区中的脚本，以及程序型脚本详情。它调用脚本原有的“运行”动作，**只打开弹窗，不自动开始执行**。文件夹、非脚本节点和数值列保留原来的行为；原按钮不可用时不代替其绕过检查。

运行弹窗默认隐藏“开始”按钮，按 **Alt+R** 开始。可在“设置 → 界面 → 脚本运行”恢复按钮显示，或直接在快捷键输入框中按下新组合键。支持 Ctrl 或 Alt 配合字母、数字、F1–F12，可同时加入 Shift；不接受单独字母、仅 Shift 组合及 Alt+F4 等系统组合。

快捷键只在当前脚本运行弹窗内生效，按钮显示或隐藏时均可使用。它触发原按钮动作，保留运行前检查、权限和运行锁；长按不会重复启动。修改设置后，已打开的运行弹窗也会更新。

### 场景对话框

对操作设置为“显示为对话框”的场景，默认采用系统标题栏、边框和关闭按钮；关闭该选项后恢复原紫色边框。两种样式下，窗口标题文字均为空。

样式可以在窗口打开期间切换，保留当前输入、选区、位置及模态状态。系统关闭按钮调用场景原有的关闭动作；存在子对话框或原生下拉弹窗时，待其关闭后应用样式。

## 临时文件保留与归档

Financial Client 和 Administrator 出现“发现未知文件”提示时，增强统一静默执行“保留文件”，适用于所有文件名称和扩展名。其他登录过期、重新登录、账户锁定、保存确认等业务提示仍由 Lucanet 处理。

| 情况 | 文件处理方式 |
| --- | --- |
| 正常退出客户端 | 在原生检查前，递归归档当前客户端临时目录中的普通文件，包括隐藏文件、空文件及子目录中的文件。 |
| 登录过期、会话超时等非退出阶段 | 文件留在原处，只静默执行“保留”。 |
| 文件被占用或无法归档 | 保留原文件，继续处理其他可移动文件。 |
| 符号链接、目录联接 | 不跟随链接，不处理临时目录边界外的内容。 |

归档针对 Lucanet 当前客户端的临时目录，不扫描整个 Windows TEMP。默认保存位置：

```text
%USERPROFILE%\LucaNet-exit-archive\日期时间-pid进程号-随机值\原相对路径
```

每次退出创建独立目录，保留子目录结构，不覆盖已有归档。需要时可从中取回文件。强制结束进程、崩溃或断电时，不保证执行正常退出归档。

## 更新与卸载

### 手动安装更新包

完整解压新的运行包，正常关闭 Manager 和所有客户端，然后运行新包中的 `enhancement.exe`，在工作区点击“安装”。仅打开新管理器不会替换已经安装的增强模块。

**同版本修订包也使用这一路径更新。** 在线检查按版本号比较，相同版本号不会被提示为新版本。Software Manager 升级并生成新的启动配置后，也需要重新安装增强，使新配置接入增强。

### 管理器内检查更新

1. 进入“设置 → 应用”，点击“检查更新”。也可以开启“自动检查更新”，在每次启动管理器时检查一次。
2. 检测到新稳定发布且提供可校验的完整 ZIP 时，点击“下载更新”。下载不会自动安装或执行。
3. 通过大小、SHA-256、路径及必需运行文件校验后，点击“应用热更新”。
4. 兼容且已安装增强的客户端可保持登录，运行中的模块及下次启动使用的模块一并更新。不兼容或无法核实进程身份时，按提示正常关闭客户端后安装。

更新成功后从下载目录启动新管理器，新窗口就绪后旧窗口关闭。再次打开请使用新目录中的 `enhancement.exe`；旧快捷方式仍指向原位置。更新期间等待操作结束，再启动或退出 Manager、执行其他安装操作。

更新器只读取项目的稳定 Releases，不把分支源码当作运行包，也不自动降级。下载或校验失败会保留原因，可重试或手动下载完整包。当前更新器兼容带 `lucanet-client-enhancement/` 外层目录及旧平铺运行包。

### 卸载

正常关闭 Manager 和所有客户端，在工作区选择对应安装目录，点击“卸载”。归档文件和配置备份保留；之后继续使用原来的 Software Manager。需要恢复增强时重新安装。

## 文件位置与常见问题

### 文件位置

| 内容 | 默认位置 |
| --- | --- |
| 已安装增强及配置备份 | `<Lucanet 安装目录>\.client-enhancement\`，备份位于其 `backups` 子目录 |
| 功能开关、快捷键及字号 | `%LOCALAPPDATA%\Lucanet\ClientEnhancement\features.properties` |
| 管理器刷新及更新偏好 | `%LOCALAPPDATA%\Lucanet\ClientEnhancement\ui.json` |
| 下载更新缓存 | `%LOCALAPPDATA%\Lucanet\ClientEnhancement\updates\` |
| 临时文件归档 | `%USERPROFILE%\LucaNet-exit-archive\` |
| Java 增强诊断日志 | `%USERPROFILE%\.lucanet-exit-enhancement\logs\` |

增强模块安装后独立保存在 Lucanet 目录，客户端日常运行不依赖下载缓存；仍从缓存启动增强管理器时，需要保留该管理器所在的完整运行目录。

### 常见问题

| 现象 | 处理方式 |
| --- | --- |
| 自动识别不到 Lucanet | 选择包含 `LucaNetSoftwareManager.exe` 的目录；避免选择某个版本子目录。 |
| 提示没有完整 JDK | 检查所选目录 `.jdk` 下是否存在带 `java`、`javac`、`jar` 的完整 JDK，不需要修改系统环境变量。 |
| 安装或卸载提示程序仍在运行 | 正常关闭同一安装目录启动的 Manager、Financial Client 和 Administrator，再检查状态。 |
| 解压后无法启动或缺少脚本 | 确认使用完整运行 ZIP，进入外层文件夹后启动，并保留全部 6 个文件及子目录。 |
| 已打开新管理器，但客户端功能未改变 | 普通更新需要点击“安装”；客户端由原启动器重新启动后加载。兼容的在线更新可使用“应用热更新”。 |
| Ctrl+Space 没有弹出补全 | 确认处于可编辑 Java 代码中且已开启编码辅助；检查输入法是否占用该组合键，首次索引可稍候重试。 |
| 额外库中的类型没有候选 | 确认该库已由当前 Lucanet 脚本上下文加载；补全不会自行下载或加载任意外部 JAR。 |
| 注解有提示，但注解生成的方法没有补全 | 编辑器不执行注解处理器；Lombok 等依赖按 Lucanet 原生方式编译。源码辅助诊断可能无法识别尚未编译的生成成员。 |
| Alt+Insert 没有响应 | 新建类型时选中 Class 文件夹并处于编辑模式；生成方法时将焦点放在完整源码窗口中，并开启 Java 编码辅助。 |
| 关闭源码窗口提示保存失败 | 保留或复制草稿，检查语法、类型重名、原脚本状态，以及节点是否在其他位置修改。 |
| 源码已保存，重开脚本却没有修改 | 源码窗口保存到 Class 后，还需要保存原脚本。 |
| 无法下载更新 | 检查网络及发布是否附带完整运行包和校验摘要；相同版本号的修订包请手动下载并安装。 |

反馈问题时，建议提供 Lucanet 客户端版本、实际使用的 JDK、复现步骤、相关截图及对应时段的日志。分享前请移除账号、连接地址和业务数据等不适合公开的内容。
