## 2026-11-20：上下键切换完整签名的流畅度

- 移除每次选中时“隐藏展开层 → 等待 120 ms → 重建”的流程。同一按键产生的选择/滚动事件仅合并到下一个 EDT 周期，不设置停留等待。长签名之间切换复用同一个不可聚焦的原生窗口，只更新内容、位置和必要尺寸，避免反复隐藏/创建窗口。
