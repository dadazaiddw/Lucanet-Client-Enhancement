# 审查与优化记录 — v1.0.5

日期：2026-11-20。基于本地工作区已有 v1.0.5 实现继续修改，保留此前未提交的工作。

本轮重点审查代码补全、导包整理、自定义类型编辑与方法生成，并回归退出处理、脚本快捷键／双击、导航、场景窗口、安装及热更新。审查与隔离测试未发现新的高危安全问题；这不代表完成了对 Lucanet 本体或全部业务脚本的安全审计。

## 发现并修复

| 级别 | 问题与触发条件 | 处理结果 |
| --- | --- | --- |
| P2 | 完整源码补全只检查显式 import 与部分类名，泛型参数、内部类或方法类型参数与待导入类型同名时，简短名称可能绑定错误。 | 使用 javac 的类型、作用域及声明信息决定名称；冲突时保留必要的全限定名，并避免新导入改变当前源码其他位置的已有类型含义。 |
| P2 | 自动把两个显式导入合并为通配导入时，未检查当前包中的同名类，包含 package-private 类；原本正确的名称解析可能改变。 | 整理导包时加入当前包候选检查，保留消歧所需的显式 import。新增同包 Class 测试复现并验证。 |
| P2 | Ctrl+O 的类定位在匿名类内部会回退到外部具名类，可能把方法插入错误的类。 | 匿名类请求保留其真实作用域，暂不提供生成；不会转移到外部类。Alt+Insert 同样受此保护。 |
| P3 | Alt+Enter／Ctrl+O 生成方法直接使用 TypeMirror 字符串，出现 `@java.lang.Override`、`java.lang.Object` 等冗余完整名称。 | 统一生成代码的名称规划，使用 `@Override`、`Object` 等短名称；泛型、数组、异常、辅助工具类型按需导入。批量生成中同名类型不会产生互相冲突的 import。 |

生成方法和 import 作为一个原生撤销单元写入。后台导包监听记录这次结果，不额外叠加一次自动整理修改。覆盖等候后台定时器后的 Ctrl+Z 验证。编译器专用类从同一隔离加载器加载，已在真实 javaagent 模式下验证，避免仅在普通 classpath 测试可用。

主要实现文件：`JavaGeneratedNames.java`、`JavaMemberGeneration.java`、`JavaGenerationDialog.java`、`JavaTypeActions.java`、`JavaUnitImports.java`、`JavaIntelligence.java`、`JavaEditorAssist.java`、`CustomJavaTypes.java`。

## 本轮新增与界面调整

- 自定义类完整源码窗口的 Alt+Insert 提供构造方法、Getter、Setter、Getter 和 Setter、equals/hashCode、toString，以及原有重写／实现方法入口。
- 字段多选、空格切换、全选／清空、父类构造器选择；菜单与选择窗口跟随字号设置，使用 Lucanet 图标。
- Generate 菜单采用居中标题、圆角和浅蓝选中状态；直接输入进行包含搜索，支持方向键、Enter、Backspace、Esc 和 Ctrl+O。菜单关闭时清理选择路径并延后执行命令，避免焦点恢复取消生成请求。
- 构造方法在有多个父类构造器时分步选择；Getter／Setter 提供列表多选；equals/hashCode 提供 Objects 模板、类型检查、equals 字段、hash 字段及非空字段向导，Back 保留选择；toString 提供拼接模板和 Getter／Override 选项。筛选保留已选字段，取消不写入源码。
- 方法插入当前光标位置，位于成员内部时移至该成员之后；保护注释、Javadoc、多变量字段声明、初始化块、嵌套类型与 CRLF。Ctrl+O 和快速修复共用插入定位。
- 对照本地 IDEA 模板调整 Getter、Setter、equals、hashCode 与 toString：多个普通字段使用 `Objects.hash(...)`，字符串输出带单引号；单字段与数组使用相应哈希函数，局部变量避免字段重名和 Java 关键字，带受检异常的 Getter 不用于生成值方法。
- 静态字段排除；已初始化的 final 字段不重复赋值；空白 final 字段强制进入构造参数；final 字段不生成 Setter。
- 检查已有方法、final/static 父方法、相同擦除但泛型不兼容的方法签名。equals/hashCode 成对生成，已有其中一个时提示而不插入另一半。
- equals/hashCode 验证数组内容、深层数组、null、NaN、正负零的一致性；toString 显示数组内容。可选父类参与，默认关闭。
- 源码窗口从固定 1080×760 改为当前屏幕可用宽度 75%、高度 70%，约半屏面积。按所在显示器 DPI 坐标布局，避开任务栏并居中；小屏幕不超出可用区域，保留调整大小与最大化。
- 项目版本按用户指定保持 v1.0.5，界面、程序集、Maven、JAR 和交付 ZIP 一致；后续未经用户确认或指定不修改版本号。
- 交付包的六个运行文件统一置于 `lucanet-client-enhancement/` 外层目录。更新器返回实际程序目录，兼容旧平铺包，并在解压前拒绝混合结构、缺少依赖及非法路径。
- README 重写为面向 GitHub 的功能与使用说明，包含安装、源码编辑、生成方法、快捷键、更新卸载、文件位置和常见问题，不记录版本日志。

## 后续优化建议

**P2，长时间频繁热更新的旧模块保留。** `AgentRuntime.java` 第 19 行的静态列表强引用每个加载器，第 51 行持续追加，`finish()` 仅清空事务模块引用。多次热更新后，旧加载器仍被列表保留，存在累积内存及模块资源占用。代码刻意允许旧调用自然结束，因此本轮未直接关闭加载器；建议单独引入可回收的加载器登记及退役模块生命周期测试，再验证旧调用、跨版本模块开放与热更新回滚。当前未做长时间堆占用测量，不把它描述成已发生的业务崩溃。

本轮字段方法生成针对普通类、抽象类、异常类；接口、枚举、Record 和注解仍使用已有 Ctrl+O 能力。没有复刻 IDEA 的全部生成器、重构与检查规则；委托方法、Logger、测试生成和可编辑生成模板可作为后续独立功能。
