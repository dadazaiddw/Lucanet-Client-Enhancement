| 功能 | 本轮结果 |
| --- | --- |
| `.var` 具体类型 | 根据 javac 归因后的类型生成声明，保留基本类型、数组、泛型、可见类型变量和内外层泛型。匿名类、捕获类型及不可访问类型使用可写且可赋值的父类型或通配符。 |
| `.var` 命名 | 从 getter、调用名称、字段/变量、数组和集合元素类型推断；避开已有名字、后续局部声明及被引用的继承字段，必要时添加数字后缀。生成后选中变量名。 |
| 导包 | 完整源码窗口自动加入导包并保留变量选区；同名类型冲突保留全限定名。原生方法编辑区复用已有导入，否则使用全限定名，避免把 import 写入方法体。 |
| 方法与构造器补全 | 自动补齐 `()`，包括无参方法；光标进入括号内部。保留已有参数、注释、构造器泛型和数组维度；方法引用补全不添加调用括号。 |
| 成对输入 | `"`、`'`、`()`、`[]`、`{}` 的左符号自动补右半边并将光标放在中间。注释、字符串内容、文本块和粘贴不做成对改写。 |
| 补充编辑便利 | 选区包裹、跳过已有右符号、空符号对退格删除、花括号内 Enter 缩进展开，保留换行格式。修改纳入原生单步撤销，关闭增强或只读时恢复原生按键。 |
| Exception 模板 | Class 文件夹中 Alt+Insert → Exception 默认 `extends RuntimeException`，保留 `String message` 构造方法及 `super(message)`。继承的原生兼容限制和红字提示继续生效。 |

示例：

```java
getCustomer().var
// Customer customer = getCustomer();

java.util.List.of("x").var
// List<String> strings = java.util.List.of("x");

new String[0].var
// String[] strings = new String[0];
```

`.var` 仅在可声明局部变量的位置提供。`void`、单独的 `null`、`super`、无法解析的类型以及不允许声明变量的单语句位置不会生成声明。复杂类型投影可能只暴露父类或接口成员；不保证还原匿名类的专有成员，也不声称覆盖完整 IDEA 的类型推断、重构与检查能力。
